# 棚区当班配水规范

每天开班前将根区探头采样、阀门遥测和计划许可一起复核。遥测时间为班次内分钟，采样行 `flow_l` 表示每分钟升数。仅对相邻且持续打开的合法读数做梯形积分，过大的缺测区不计已供水。

以根区探头中位深度为参考，选择 15 厘米以内且至少两支无冲突探头。`moisture` 是体积含水率，`solar` 为当日表辐射读数，`temp_c` 是摄氏温度，`humidity` 为相对湿度比例。观测按采样日与首次发布日期限制可见性。

各作物训练岭回归，特征按训练期中心与尺度转换，带主元高斯消元求解正则化正规方程。最近六天留作残差校准，按残差经验分位补成双尾区间。对新增域外高光照、遥测缺测、根区过湿或缺少校准的棚区挂起申请。

总班次额度以百升调整，另有独立泵容与阀门分钟限制。第一轮按可用额度和保底申请做整数比例分配，其余交给干燥程度最高工区。计量单为累计量差，逐单按分区授权累计校核。

### 班表和次班交接

不同泵组可同时供水，同一泵组的时段不能重叠。排班先合并泵组开放窗口，再扣除检修和临时停水，最后按根区干燥程度为已授权棚区切分分钟。全部分钟时段采用左闭右开区间，最后一分钟按所需余量截断。

班次回放以前缀中首次发布日期早于试算日的记录拟合，最近一周历史中位用量为参照。岭惩罚系数在更早的一组日期内选取。值班人员可看每个作物实际需水与预估偏差、关闭阀位残流、未排入的授权量以及累计计量单待查额。次班交接保持授权量等于已排量与未排量之和。
